# 큐아이(QI) 능동형 도슨트 — 웹 데모 (1인칭 3D 전시실 + iPhone)

## 실행
- **`start.command` 더블클릭**, 또는 터미널에서 `cd app && python3 -m http.server 8000` 후 크롬으로 `http://localhost:8000/`
- 카메라·시선 인식은 `localhost` 또는 HTTPS 에서만 동작합니다. 파일을 직접 열면 카메라가 꺼집니다.
- **노트북 시연용입니다.** 화면 전체가 3D 박물관이고, 오른쪽 아래에 iPhone(큐아이 앱)이 있습니다.
- `?world=0` 을 붙이면 3D 없이 폰 화면만 나옵니다. 창 너비가 900px 이하이거나 WebGL이 없을 때도 자동으로 그렇게 됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| 3D 화면 클릭 | 마우스 시점 잠금 (Esc 로 해제) |
| 마우스 | 시선(방향) 조정 |
| W A S D / 방향키 | 이동 · Shift 달리기 · Q E 좌우 회전 |
| **F** | "폰을 쳐다봄" (웹캠이 없을 때). 질문이 뜨면 마우스가 자동으로 풀려서 폰을 직접 클릭할 수 있음 |
| Space / L / N | (시연 도구) 보는 중 / 폰 보기 / 끄덕임 수동 입력 |
| **G** 또는 상단 "자동 이동" 버튼 | 큐아이가 길안내 선을 따라 다음 유물 앞까지 약 6초 만에 데려다 줌 (걷기 키를 누르면 즉시 중단) |
| 시연 도구 > 유물 버튼 | 그 유물 앞으로 이동 |

## 시연 흐름
1. 폰에서 **Get started** → 큐아이가 시간을 묻는다 (15분~3시간 프리셋 7개, 슬라이더, **"시간 상관없이 자유롭게"**, 말이나 글로도 가능). 시간이 짧으면 유물 수가 줄고, 자유 관람은 전부 돈다.
2. 바닥의 **파란 길안내 점**과 상단의 "➜ 다음 유물 · 거리"를 따라 걷는다. 왼쪽 아래 미니맵에 내 위치와 다음 유물이 보인다.
3. 유물 앞에서 **시점을 유물에 두면**(십자선) 시선이 머무는 것으로 판단 → 4초 후 신호(오브 색 변화) → 유도(소리·진동) → 폰을 보면(웹캠으로 정면을 보거나 F) 질문
4. "네"(탭) / 3초 바라보기 / 끄덕임(웹캠) → 해설 채팅 → 퀴즈 → 퍼즐 → 도감 수집 → 다음 유물
5. 웹캠은 오브에 **볼록거울처럼 아주 은은하게** 얼굴 형태만 비친다(심하게 흐리고 남보라 톤). 얼굴이 인식되면 조금 진해지고, 안 보이면 옅어진다. 그리고 **끄덕임과 폰 쳐다보기** 감지에 쓴다. (3D 모드에서는 시선 머묾을 웹캠이 아니라 게임 시점으로 판단)

## 자유 관람 (유물 27점 + 시나리오 유물 5점)
- 고구려관(105)·백제관(106)·신라관(108-110)에는 시나리오 유물 외에 **자유 관람 유물**이 놓여 있다. 고구려 10점, 백제 8점, 신라 9점.
- 유물을 **시점 가운데에 두고 1.6초쯤 바라보면** 화면 왼쪽 아래에 설명 카드(사진·이름·나라·한 줄 설명)가 뜨고, 큐아이가 그 나라의 목소리로 읽어 준다. 한 번 본 유물은 **도감**에 담긴다(도감 32칸).
- 코스(시나리오)와 상관없이 어느 방, 어느 유물이든 자유롭게 볼 수 있다. 오래 본 나라는 취향 카드에 반영된다.
- 유물 설명과 이름은 `exhibits.js`에서 고친다(4개 언어). 사진은 `assets/exhibits/<id>.jpg`.
- 방 분위기: 고구려관=어두운 방+뒤에서 빛나는 탁본, 백제관=밝은 흰 방+치미 단상, 신라관=따뜻한 나무 바닥+육각 진열장. (`박물관 배경/` 사진 기준)

## 큐아이와 음성 대화
- 폰 아래 **마이크 버튼**을 누르면 대화 모드가 켜진다(다시 누르면 꺼짐). 말하면 큐아이가 알아듣고 소리 내어 답한 뒤 다시 듣는다. 큐아이가 말하는 동안에는 듣지 않는다.
- 알아듣는 말(영·한·일·중): 인사, "누구야", "다음", "남은 시간", "이거 설명해 줘", "데려가 줘"(자동 이동), "조용히 해"/"다시 말 걸어", "영어로 말해 줘", 도움말, 그리고 "1시간 있어요" 같은 시간 알림.
- 말한 언어를 자동으로 알아듣고 그 언어로 답한다. 유물 앞에서는 "누가 만들었어요?" 같은 질문에도 답한다.
- 자유 대화(LLM)는 연결하지 않았다. 직접 만든 프록시를 `window.QI_LLM_ENDPOINT`(또는 localStorage `qi_llm`)에 넣으면 알아듣지 못한 말을 그쪽으로 보낸다. 요청 `{text, lang, artifact, course}` → 응답 `{reply}`.
- 음성 인식은 크롬(구글 서버 사용)에서 동작한다. 마이크 허용이 필요하다.

## 나라별 목소리
해설할 때 나라마다 말투가 다르다: 고구려는 낮고 힘차게, 백제는 부드럽고 천천히, 신라는 밝고 화려하게, 가야는 깊고 느리게, 금동대향로는 아련하게. 기기에 남녀 음성이 있으면 성별도 맞춰 고르고, 없으면 높낮이와 속도로 구분한다. (음성 종류는 기기에 설치된 것에 따라 다르다.)

## 분위기 레퍼런스
3D 전시실은 `museum background/`의 사진 2장을 따랐다: 전시실은 어두운 차콜 톤 + 검은 진열장 + 천장 선형 조명 + 바닥의 밝은 안내선, 대공간은 베이지 석재 벽 + 천창 + 반짝이는 바닥 + 검은 석탑. 앱 색감은 `app color concept/`의 청자(옥색) 안개 톤, 복숭아·민트 파스텔, 하늘색 유리 느낌을 따랐다.

## 전시실 배치 (실제 국중박 1층)
`docs/research/nmk-1f-layout.md` 참고. 출입구 → 대공간("역사의 길", 경천사 십층석탑) → 오른쪽 날개:
101 구석기 → 102 신석기 → 103 청동기 → 104 고조선·부여·삼한 → **105 고구려(호우 청동합) → 106 백제(산수무늬 벽돌) → 107 가야(투구와 판갑옷) → 108-110 신라(금관과 금허리띠)**
- 120분 코스에는 백제실에 "없는 유물"(금동대향로) 빈 진열대가 추가된다.
- 배치도 이미지에서 읽은 근사 레이아웃이며 정확한 치수가 아니다. 101–104실의 진열품은 분위기용 임시 소품이다.

## 유물 이미지 넣기
시나리오 유물 중 백제 산수무늬 벽돌·신라 금관·금동대향로는 `assets/exhibits/`의 사진을 쓴다. 고구려 호우 청동합과 가야 판갑옷은 사진이 없어 임시 3D 도형이다. 토이 스타일 이미지(`docs/artifact-image-prompts.md`)를 아래 이름으로 저장하면 사진 대신 쓴다. 다음 새로고침부터 3D 진열대에 나타납니다. (흰 배경은 코드에서 투명 처리)
`app/assets/artifacts/` → `gogu.png`, `baek.png`, `silla.png`, `gaya.png`, `absent.png`
이미지가 없으면 임시 3D 도형이 나옵니다.

## 언어
- 기본 영어. 기기 언어가 일본어·중국어면 그 언어로 시작. 글자나 음성으로 일본어·중국어·한국어를 쓰면 자동 전환. `?lang=ja` 로 지정 가능.

## 알려진 한계
- 전시실은 공식 배치도를 근사한 가상 공간입니다. 유물이 지금 실제로 진열 중인지는 발표 전에 확인해야 합니다.
- 웹캠 시선은 얼굴 방향 기반 근사입니다. 3D 모드의 "유물을 보는 중"은 게임 시점으로 판단합니다.
- 자유 질문은 준비된 문답에 키워드로 답합니다. LLM은 연결하지 않았습니다.
- 음성은 브라우저(OS)에 설치된 음성을 씁니다. 설정 > 목소리에서 바꿀 수 있습니다.
- iPhone 진동은 iOS 17.4 이상 우회법이며 불안정합니다. 노트북 시연에서는 화면 흔들림으로 대체됩니다.
